Request Data Flow

01
User Action
User selects a filter in FilterBar.vue
02
Reactive State
useFilters() singleton ref updates (e.g. selectedLocation)
03
Watcher Fires
View's watch([...filters]) callback calls loadData()
04
Build Request
api.js constructs URLSearchParams from getCurrentFilters()
05
HTTP GET
Axios sends GET /api/orders?warehouse=Tokyo&month=2025-01
06
Route Handler
FastAPI receives optional query params
07
Filter & Return
apply_filters() + filter_by_month() run sequentially over in-memory list
08
Re-render
View receives filtered JSON; computed properties update DOM

Filter Parameter Mapping

Frontend ref
Time Period
selectedPeriod
→ month param ("2025-01" or "Q1-2025")
Warehouse
selectedLocation
→ warehouse param ("San Francisco"…)
Category
selectedCategory
→ category param ("sensors"…)
Order Status
selectedStatus
→ status param ("Delivered"…)
→
Backend behavior
Value = "all"
Param omitted from request. Backend receives None, skips that filter entirely.
apply_filters()
Applies warehouse, category, status sequentially. Case-insensitive matching.
filter_by_month()
Handles month ("2025-01") and quarter ("Q1-2025") using QUARTER_MAP dict.
Scope
Inventory ignores month (no time dimension). Demand & Backlog ignore all filters.
